# Browser icons

These square icons reuse the existing D5 brand symbol in `../d5-logo.png`.
The source image is a 250 × 100 logo lockup; the symbol occupies the leftmost
100 × 100 pixels. The wordmark is excluded to prevent favicon distortion.

- PNG: 16, 32, 48 and 180 pixels; the 180px export is the Apple touch icon.
- ICO: contains 16, 32 and 48px PNG entries.
- The HTML uses new icon paths and an explicit version query to avoid the
  browser's cached wide logo.

These are exports of the existing project artwork, not files downloaded from
the live D5 website: its favicon could not be retrieved in this environment.
